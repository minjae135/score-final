# 중학교 내신 성적 산출기

중학교 학기별 교과 성적과 출결·자율활동·동아리 활동·봉사활동 점수를 입력해 300점 만점 기준 내신 성적을 산출하는 웹 앱입니다.

## 주요 기능

- 일반교과의 원점수 또는 A~E 성취도로 환산점수를 입력합니다.
- 체육·음악·미술은 원점수 또는 A~C 성취도로 입력하며, 기본 방식은 성취도입니다.
- `평가별` 입력에서 과목별 지필·수행 평가의 점수, 만점, 반영비율을 관리합니다.
- 과목별 입력과 학기 평균 직접 입력을 지원합니다.
- 앞선 학기의 입력 완료 성적을 바탕으로 이후 학기 점수를 예상합니다.
- 입력 상태를 JSON 파일로 저장하고 다시 불러올 수 있습니다.
- 학년별 기본 과목을 제공합니다. 학교별 과목 편성에 따라 과목을 추가하거나 삭제할 수 있습니다.
- 1학년 1학기는 자유학기로 기본 설정되며, 점수 산출에서 제외됩니다. 성적이 있다면 과목별 또는 평균으로 입력해 예상 대체 성적에 활용할 수 있습니다.
- 미인정 결석 일수를 입력해 최대 21점의 출결 점수를 계산하고, 교과 점수와 합산합니다.
- 자율활동 점수를 학년별 2~4점으로 입력합니다. 기본 3점씩 총 9점으로 시작하며 최대 12점입니다.
- 동아리 활동 점수를 학년별 2~4점으로 입력합니다. 기본 3점씩 총 9점으로 시작하며 최대 12점입니다.
- 봉사활동 실적을 기준시수별 학년 점수(2·3·4점)로 입력하고, 해당 시 기본계획 가산점을 학년별 1점씩 추가합니다. 최대 15점입니다.

## 환산 규칙

총점은 기본점수 96점과 실질 반영점수 최대 144점으로 구성됩니다.

총점은 교과성적 240점, 출결 최대 21점, 자율활동 최대 12점, 동아리 활동 최대 12점, 봉사활동 최대 15점을 합한 300점입니다. 출결은 미인정 결석 0일이면 21점이며, 이후 2일마다 1점씩 감점하고 17일 이상이면 12점입니다. 입력한 결석 일수에 따른 점수는 `max(12, 21 - ceil(일수 / 2))`로 계산합니다. 자율활동과 동아리 활동은 학년별 기본 3점이며, 해당 가산 대상은 4점, 감점 조건에 해당하면 2점으로 입력합니다. 봉사활동은 학년별 기준시수 충족 4점, 기준시수의 절반 이상 3점, 절반 미만 2점에 기본계획 가산 해당 시 학년별 1점을 추가합니다.

| 학기 | 반영 계수 |
| --- | ---: |
| 1학년 1학기 | 자유학기 기본값, 반영하지 않음 |
| 1학년 2학기 | 2.88 |
| 2학년 1·2학기 | 학기당 5.76 |
| 3학년 1·2학기 | 학기당 7.2 |

일반교과는 원점수 90점 이상 A(5점), 80점 이상 B(4점), 70점 이상 C(3점), 60점 이상 D(2점), 60점 미만 E(1점)로 환산합니다. 성취도를 직접 입력하는 경우 A~E를 각각 5~1점으로 계산합니다.

체육·음악·미술은 성취도 A/B/C를 각각 5/4/3점으로 계산합니다. 원점수 입력 시에는 80점 이상 5점, 60점 이상 4점, 60점 미만 3점으로 환산합니다.

과목 입력 방식을 `평가별`로 선택하면 평가 항목별 획득점수와 만점, 반영비율을 입력합니다. 기본 비율은 일반 과목 30/30/20/20, 수행평가 전용 과목 50/50, 정보 40/30/30, 영어 30/30/10/30이며 항목 이름·순서·비율은 수정할 수 있습니다. 가중 평균은 정수로 반올림한 뒤 해당 과목 구분의 원점수 환산 기준을 적용합니다. 설정한 반영비율 합계는 100%여야 합니다. 인정 미응시 평가는 제외하고 나머지 비율을 자동으로 100%에 맞춥니다. 점수를 입력하지 않은 평가는 임시 계산에서 제외되며, 미인정 미응시는 획득점수 0점으로 입력합니다.

환산 결과는 소수점 셋째 자리까지 표시합니다.

## 예상 점수

학기별 `예상`을 선택하거나 상단의 `미입력 학기 예상`을 누르면, 안내된 대체 학기 규칙에 따라 **첫 번째로 입력 완료된 대체 학기의 평균 환산점수**를 그대로 적용합니다. 같은 학년의 반대 학기를 먼저 확인하고, 해당 학기 성적이 없으면 안내된 다른 학년 대체 기준을 순서대로 확인합니다. 예상 학기와 자유학기는 대체 기준으로 사용하지 않습니다. 1학년 1학기의 실제 성적을 활용하려면 해당 학기를 과목별 또는 평균 입력으로 변경하세요. 대체할 입력 완료 성적이 하나도 없으면 예상값을 계산할 수 없습니다.

## 실행

Node.js와 npm이 설치된 환경에서 실행합니다.

```bash
npm install
npm run dev
```

빌드와 테스트는 다음 명령으로 실행합니다.

```bash
npm run build
npm test
```

빌드 결과는 `dist/`에 생성됩니다. `.github/workflows/pages.yml`이 기본 브랜치(`main` 또는 `master`)에 푸시될 때 빌드하고 GitHub Pages에 자동 배포합니다. 저장소 Settings의 Pages에서 배포 원본을 `GitHub Actions`로 설정해 주세요.

## 성적 파일

`저장`은 현재 입력 상태를 JSON 파일로 다운로드합니다. `불러오기`에서 이 파일을 선택하면 입력 상태를 복원합니다. 입력 데이터는 서버에 전송되지 않으므로, 브라우저를 닫거나 새로고침하기 전에 보관하려면 파일로 저장해 주세요.
