# 중학교 교과성적 환산 점수 계산기

중학교 학기별 성적을 입력해 240점 만점 기준 교과성적 환산 점수를 계산하는 웹 앱입니다.

## 주요 기능

- 일반교과의 원점수 또는 A~E 성취도로 환산점수를 입력합니다.
- 체육·음악·미술은 A~C 성취도로 입력합니다.
- 과목별 입력과 학기 평균 직접 입력을 지원합니다.
- 앞선 학기의 입력 완료 성적을 바탕으로 이후 학기 점수를 예상합니다.
- 입력 상태를 JSON 파일로 저장하고 다시 불러올 수 있습니다.
- 학년별 기본 과목을 제공합니다. 학교별 과목 편성에 따라 과목을 추가하거나 삭제할 수 있습니다.

## 환산 규칙

총점은 기본점수 96점과 실질 반영점수 최대 144점으로 구성됩니다.

| 학기 | 반영 계수 |
| --- | ---: |
| 1학년 2학기 | 2.88 |
| 2학년 1·2학기 | 학기당 5.76 |
| 3학년 1·2학기 | 학기당 7.2 |

일반교과는 원점수 90점 이상 A(5점), 80점 이상 B(4점), 70점 이상 C(3점), 60점 이상 D(2점), 60점 미만 E(1점)로 환산합니다. 성취도를 직접 입력하는 경우 A~E를 각각 5~1점으로 계산합니다.

체육·음악·미술은 성취도 A/B/C를 각각 5/4/3점으로 계산합니다.

환산 결과는 소수점 셋째 자리까지 표시합니다.

## 예상 점수

학기별 `예상`을 선택하거나 상단의 `미입력 학기 예상`을 누르면, 해당 학기보다 앞선 **입력이 완료된 실제 학기 평균**들의 산술평균을 예상 평균 환산점수로 사용합니다. 예상 학기는 점수표에 별도로 표시됩니다. 입력된 과거 학기가 없으면 예상값을 계산할 수 없습니다.

## 실행

Node.js와 npm이 설치된 환경에서 실행합니다.

```bash
npm install
npm run dev
```

빌드와 테스트는 다음 명령으로 실행합니다.

```bash
npm run build
npm test
```

빌드 결과는 `dist/`에 생성됩니다. GitHub Pages에 배포하려면 GitHub Actions에서 이 빌드를 실행하고 `dist/`를 게시하도록 설정해야 합니다.

## 성적 파일

`저장`은 현재 입력 상태를 JSON 파일로 다운로드합니다. `불러오기`에서 이 파일을 선택하면 입력 상태를 복원합니다. 입력 데이터는 서버에 전송되지 않으므로, 브라우저를 닫거나 새로고침하기 전에 보관하려면 파일로 저장해 주세요.
